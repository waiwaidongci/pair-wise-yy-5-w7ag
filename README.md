# 手工织锦纹样排版台

直接打开 `index.html` 使用。支持网格绘制、色线统计、撤销重做、本地保存和导出 JSON。

## 离线协作与回传合并

方案记录**基准修订号**（r1、r2、…），每次正式保存递增，且每个修订号保留格子快照。

1. **导出离线稿**：在排版台保存确认后导出，文件带 `baseRevision`，带去打样间离线编辑。
2. **回传合并**：打样间导出回传稿（带同一基准修订号和唯一回传标识），排版台点「回传合并」做**三路合并**：
   - 只有一边改过的格子自动合并（蓝框标记）；
   - 双方改成不同颜色的格子保留两份值，斜纹高亮、逐格点击选择（也可「全部选本端值/对方值」）；
   - **冲突全部处理完之前，不能正式保存、不能生成交付包、不能再导出离线稿**；也可放弃本次回传恢复原状。
3. **确认保存**：冲突选完后「确认并正式保存」生成新修订号。重复回传（同一回传标识，或同基准下内容指纹相同）只认首次。
4. **旧稿迁移**：没有基准修订号的旧稿/旧回传文件按首版迁移——现有内容为 r1，合并基准 r0 视为空网格。
5. **按修订号恢复**：修订历史面板可恢复任意历史修订号为工作稿（另存为新修订号，不覆盖历史）；写入失败时自动回滚恢复到上一份落库修订号。

## 用色统计、断线风险与交付包

- 任一格色号变化，用色统计与断线风险立即按当前格子重算，并标记为「格色已变」；正式保存后按修订号标记为已计算。
- 交付包（含格子、用色统计、断线风险行、修订号、生成时间）只有在无未处理冲突、工作稿已落库时才能生成。
- 格色进入新修订号后旧交付包标记为**失效，需重新生成**；所有旧交付包都在「交付包」面板保留快照，可随时重新下载。
