# 手工织锦纹样排版台

直接打开 `index.html` 使用。支持网格绘制、色线统计、撤销重做、本地保存、导出草稿，以及离线回传三路合并与交付包快照。

## 方案与修订号

- 每个方案记录当前修订号与基准修订号（`baseRevision`）。保存方案即生成一个新修订号，基准修订号同步更新。
- 旧版存档没有基准修订号时，打开自动按**首版（修订号 1）迁移**；旧稿回传文件没有基准修订号时同样按首版迁移。

## 离线回传三路合并

1. 点「导出草稿」生成带基准修订号的 JSON 草稿，离线带去打样间。
2. 双方各自改完后，点「回传合并」读入回传稿。程序以基准修订号为底做三路合并：
   - 只有一边改过的格子 → 自动合并；
   - 双方改后相同的格子 → 自动合并；
   - 双方改出不同颜色的格子 → 保留我方/对方两份值，逐格选择。
3. 冲突格在网格中以虚线标出，点击可在我方/对方颜色间切换，也可「全部保留我方 / 全部采用对方」。
4. **冲突全部处理完才能保存方案或生成交付包**。
5. 同一回传稿重复导入只认首次（按指纹去重），第二次忽略。

## 用色统计与交付包

- 任一格色号变化，用色统计与断线风险即标记为**已失效**（面板顶部提示）。
- 保存方案或生成交付包时按当前格子重算统计与断线风险；交付包保存快照，**旧交付包快照保留不变**，可随时「查看快照」。

## 写入失败恢复

- 本地存储写入失败时弹出提示，可「按修订号恢复」。
- 「修订历史」列出全部修订，可输入修订号恢复到任意版本。
